Ohne Token: Käufe per Button nur lokal in diesem Browser gespeichert — kein Verkaufssignal-Check über die Website-Updates und kein Telegram-Bericht. Mit Token: Positionen werden direkt ins Repo geschrieben, der tägliche Rebuild prüft Stop/Verkaufssignal automatisch. Token anlegen: github.com → Settings → Developer settings → Fine-grained tokens → nur Repo "trading-signal", Berechtigung "Contents: Read and write". Der Token liegt nur in deinem Browser (localStorage).
Regel-Logik: Entry nur 0–1×ATR über steigender 21dma-Struktur · Risiko 0,25 % (Schwäche) / 0,5 % (Bestätigung) / max 1 % (High Conviction) · Trim ⅓ bei 2R · Runner bis Tagesschluss unter 21-EMA-Low · Kein Markt-Gate = kein neues Risiko · Watchlist: Tagesschluss unter Stop = Verkaufssignal.

⚠️ Keine Anlageberatung. MCO/MCSI sind eine Näherung aus dem liquiden Universe, keine NYSE-Originaldaten. Das System ist diskretionär ausgelegt — Signale ersetzen kein eigenes Urteil.
